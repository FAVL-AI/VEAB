# VEAB Replay — controlled external description

VEAB Replay is a read-only evaluation and trace-analysis tool for autonomous-system research teams. It supports replayable inspection of simulator traces and selected externally recorded data against explicit task requirements.

The v0.6 engineering package implements a frozen cross-engine input-tape contract (`E100`) and demonstrates deterministic generation of that tape in an offline fixture (`E101`). It does not demonstrate native Isaac Lab execution or calibrated engine equivalence.

Selected multi-user and audit interfaces were implemented in an internal research-pilot snapshot (`E102`), but production-ready and enterprise-grade status are **not claimed**. Independent organisational validation, physical-robot safety, source authenticity, and external certification are pending.
