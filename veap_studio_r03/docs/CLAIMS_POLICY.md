# Claim control: Implementation, Demonstration, Validation, Certification

Every user-facing VEAP capability claim must name the evidence, conditions, data source and limitation.

- `IMPLEMENTED`: a software path exists and designated tests pass.
- `DEMONSTRATED`: a controlled experiment executed reproducibly in its stated environment.
- `VALIDATED`: independently supported fitness for a specific intended use; this is not equivalent to test pass.
- `CERTIFIED`: accredited certification for a named scope; none is claimed.

Statements that are *not* supported by R0.3: calibrated robot digital twin; native Isaac/MuJoCo parity; physical functional-safety guarantees; autonomous movement of an M3 Pro; source-authenticated MCAP; full enterprise IAM; external security assurance; real-time photorealistic ray tracing; state-of-the-art benchmark superiority.

A hash chain checks record continuity, not the truth of its original observation. A synthetic 2D trajectory does not prove native 3D physics. MuJoCo/Isaac module detection is not native execution.
